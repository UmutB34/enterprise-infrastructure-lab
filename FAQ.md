# FAQ and known limitations

**Which license?** MIT (see LICENSE). Contributions are accepted under the same license.

**Is this real?** The content is sanitized from real work or a real small lab. Where a result is not mine to publish, the text says so. Nothing here is an employer document.

**Does it work on Windows and Linux?** The only code is `scripts/check_redaction.py` (Python 3, standard library). Tested on Windows 11, Python 3.12. Linux/macOS: expected to work, not yet run by the author (unverified).

**Can I reuse a document?** Yes under MIT; keep the license notice.

## Known limitations
- Reflects one person's experience; patterns need adapting to your size, law and risk.
- The redaction check is a first pass; human review is still required.
- English only for now; Turkish is planned as the second language.
- Documents can age. Each file should carry a date; if you find one outdated, open an issue.
